Local desktop observer

TINY-PROPOSAL local substitute for viewing. Not AWS DCV. Unauthenticated: keep this server on loopback. Select a live MCP session. Stop closes only the selected MCP session (sequences stop between steps; an admitted action may finish), releasing held input and ending forwarding. It is not a lockout: new sessions remain allowed, and clients or agents may start one after the stopped session is rejected (HTTP 404, or Unknown mcpSessionId in the modern dialect). See the MCP Streamable HTTP spec. To keep an agent off the desktop, stop the agent/MCP client or the tinyAgentAccess server.

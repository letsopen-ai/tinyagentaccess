# Security

This pre-alpha server has no authentication. Keep it on loopback and do not expose it. Origin and Host checks reduce browser and DNS-rebinding risks; they do not authenticate local processes.

Report vulnerabilities privately through this repository's GitHub **Security → Advisories → Report a vulnerability** at https://github.com/letsopen-ai/tinyagentaccess/security/advisories/new. Do not publish sensitive details in public issues. Security support currently targets the latest source revision only.
